Activity 3

Guided Custom GPT Plugin Setup

Build, privately install, and test the Department KPI Planning Assistant skills-only plugin.

40 minutes
Objective: Understand the components of a reusable AI assistant by creating, privately installing, and testing a skills-only plugin with ChatGPT Plugin Creator.

Step 1: Review the Scenario

Scenario: Department KPI Planning Assistant

Every department prepares an annual KPI plan and reviews its performance regularly.

Managers often face several challenges:

  • KPI definitions are inconsistent.
  • Some KPIs are not clearly connected to departmental objectives.
  • Targets may be unrealistic or difficult to measure.
  • KPI information is stored across reports, spreadsheets, policies, and previous plans.
  • Managers spend significant time analysing performance gaps.
  • Preparing action plans and executive summaries requires repeated manual work.
  • Different departments use different reporting styles.

The organisation wants to create a Department KPI Planning Assistant that can support any department. The AI assistant should help managers:

  • Review departmental objectives.
  • Recommend suitable KPIs.
  • Check whether each KPI is specific and measurable.
  • Compare current performance with the target.
  • Calculate and explain performance gaps.
  • Suggest realistic improvement actions.
  • Identify risks that may prevent KPI achievement.
  • Prepare KPI plans and performance summaries.
  • Use uploaded organisational documents as its primary knowledge source.
  • Clearly distinguish between information found in documents and assumptions made by AI.

The GPT will support managers but will not approve KPIs, change official targets, or make final management decisions.

Step 2: Plan the Plugin Skill

A skills-only plugin packages reusable instructions and reference documents. In this activity, its central component is the skill: the instructions governing purpose, role, operating workflow, boundaries, style, and outputs. No custom API, MCP server, or external account connection is required.

A useful Plugin Instructions Framework can include the following components:

R-P-U-T-W-K-C-H-C-S-O-E-H
CodeComponentWhat it definesExampleYour plan

As a group, map the scenario to the framework. Plugin Creator will turn the instructions from the creation prompt into a reusable skill. You do not create a SKILL.md file yourself.

Step 3: Build the Plugin

Follow these instructions in order. You will paste one creation prompt, printed immediately after the numbered actions. Do not paste the prompts used later for testing at this stage.

  1. In ChatGPT, open the left sidebar and select Plugins. Find and install “Plugin Creator” if it is not already installed. Alternatively, start a new chat and select or mention “@plugin-creator” if available.
  2. Start a new chat with Plugin Creator. Confirm you are working in your intended personal account or approved university workspace.
  3. Click the file-attachment control in that same conversation. Select only the original four KPI files listed in the prompt. Do not attach this handout.
  4. Copy the Plugin Creation Prompt below.
  5. If Plugin Creator asks for clarification, tell it: “Use a PRIVATE skills-only plugin, no external integrations. Use the four ORIGINAL files I attached and the exact instructions in my creation message.”
  6. Before accepting the creation result, check that the skill includes all 13 sections, the reference inventory contains the four originals, and all 3 Excel worksheets are accessible.
  7. Complete any final confirmation or installation step shown. Choose PRIVATE access. Do not select public listing or workspace sharing. Open the created plugin in ChatGPT for testing.

If you cannot find Plugin Creator: Ask the facilitator to verify plugin availability and workspace permissions. Do not switch silently to a Custom GPT or another workflow; record the blocker.

Plugin Creation Prompt

Hint: The plugin can be accessed by typing @Department KPI Planning Assistant in the chat and selecting it from the list.

Step 4: Test the Installed Plugin

All participants must use the same test requests.

If a test fails

  • Do not change the original KPI reference files or their values.
  • Return to the Plugin Creator conversation, or mention @plugin-creator with your existing plugin, and explain the specific failed test.
  • Ask it to correct the skill or reference access, update the existing plugin, and run the failed test again.
  • Record any limitation rather than declaring success. Creating the plugin alone does not prove the reference files are accessible.
